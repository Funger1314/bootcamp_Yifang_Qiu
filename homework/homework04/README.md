# Stage 04: Data Acquisition and Ingestion

This homework adds two reproducible raw-data ingestion workflows for the S&P 500 volatility project.

## Sources

- API: [Yahoo Finance chart endpoint](https://query1.finance.yahoo.com/v8/finance/chart/%5EGSPC), used to request daily S&P 500 (`^GSPC`) prices for the date window in `.env`.
- Scrape: [Wikipedia's List of S&P 500 companies](https://en.wikipedia.org/wiki/List_of_S%26P_500_companies), used to collect a small table of the first 10 index constituents.

## Contents

- `homework04_data-acquisition-and-ingestion_submission.ipynb`: executed workflow, source documentation, validation, and assumptions.
- `.env.example`: shareable configuration template.
- `data/raw/`: timestamped API and scraped CSV snapshots generated by the notebook.

## Run

From the repository root, install dependencies and start Jupyter:

```bash
pip install -r project/requirements.txt
jupyter lab
```

Copy `.env.example` to `.env` if it is missing, then run every notebook cell. The repository `.gitignore` excludes `.env`, so local configuration is never committed. The Yahoo endpoint used here is public and does not need an API key; the `.env` file makes the ticker, date range, and timeout configurable.

The saved files are raw snapshots for coursework. They are not cleaned, investment advice, or a substitute for licensed market data.
