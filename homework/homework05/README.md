# Stage 05: Data Storage

This homework builds a reproducible storage layer for the S&P 500 volatility project. It reuses the raw S&P 500 price snapshot collected in Stage 04, saves an unchanged raw CSV snapshot, writes a processed Parquet table, and creates a JSON data-lineage manifest.

## Storage Plan

- `data/raw/`: source-faithful CSV snapshots and JSON metadata. Raw files are append-only snapshots, named with a UTC timestamp.
- `data/processed/`: typed Parquet datasets with derived columns. Parquet is preferred for analysis because it preserves data types and supports efficient column reads.
- `.env`: local path configuration. It is ignored by Git; `.env.example` is the committed template.
- `src/storage_utils.py`: reusable suffix-based CSV/Parquet read and write functions.

## Contents

- `homework05_data-storage_submission.ipynb`: executed storage, reload, and validation workflow.
- `data/raw/`: a CSV price snapshot and its JSON lineage manifest generated by the notebook.
- `data/processed/`: a Parquet dataset with a derived daily return column.

## Run

From the repository root, install the project dependencies and start Jupyter:

```bash
pip install -r project/requirements.txt
jupyter lab
```

Copy `.env.example` to `.env` if needed, then run all cells. The notebook expects the Stage 04 Yahoo Finance CSV in `../homework04/data/raw/`; that file is versioned in this repository.
