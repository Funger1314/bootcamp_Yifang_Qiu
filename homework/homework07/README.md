# Stage 07: Outliers + Risk Assumptions

This submission follows the Stage 07 starter workflow. It generates the seeded
115-row teaching dataset under `data/raw/`, applies reusable IQR and Z-score
detectors, compares all/IQR-filtered/winsorized treatments, and documents how
outlier assumptions change summary and regression results.

## Required Deliverables

- `homework07_outliers-risk-assumptions_submission.ipynb`: fully executed submission notebook.
- `data/raw/outliers_homework.csv`: deterministic CSV generated by the notebook Setup cell.
- `src/outliers.py`: documented functions with the exact starter signatures:
  - `detect_outliers_iqr(series, k=1.5)`
  - `detect_outliers_zscore(series, threshold=3.0)`
  - `winsorize_series(series, lower=0.05, upper=0.95)`
- `data/processed/outlier_flags.csv`: source rows plus boolean IQR and Z-score flags.
- `data/processed/sensitivity_summary.csv`: mean, median, and standard-deviation comparison.

- `reports/outlier_treatment_comparison.png`: before/after boxplot and time-context flags.
- `reports/regression_residual_sensitivity.png`: residual plots for all three treatments.

## Method and Key Result

IQR with `k=1.5` is the primary robust rule; an absolute population Z-score
above `3.0` is the secondary comparison. Winsorization clips both modeled return
columns at their 5th/95th percentiles as a sensitivity treatment, not as a claim
that the shocks are errors.

| Result | Value |
|---|---:|
| Observations | 115 |
| IQR flags | 9 (7.8%) |
| Z-score flags | 5 (4.3%) |
| Both-method flags | 5 |
| All-data return standard deviation | 0.0406 |
| IQR-filtered standard deviation | 0.0094 |
| Winsorized standard deviation | 0.0106 |
| All-data regression R-squared | 0.962 |
| IQR-filtered regression R-squared | 0.574 |
| Winsorized regression R-squared | 0.689 |

Filtering reduces dispersion but also removes shared shocks that carry real
correlation. The notebook therefore preserves the raw observations and flags,
reports every treatment, and makes no causal, predictive, or trading claim.

## Assumptions and Risks

- The synthetic dataset is the complete assignment sample; real return data may have missingness, serial dependence, regime changes, and heavier tails.
- IQR and Z-score thresholds are sample-dependent decision rules, not labels of data error.
- Filtering can remove the rare stress events most relevant to risk management.
- Winsorization retains rows but changes tail magnitudes and therefore must remain visible to stakeholders.
- Regression comparisons are in-sample diagnostics. They do not establish causality or forecast performance.
